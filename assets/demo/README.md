# Product Demonstration Video Checklist

A genuine end-to-end screen recording / hardware demonstration should be placed here (`assets/demo/`):

- Recommended format: `sage-demo.mp4` (<= 25 MB, or uploaded directly to the GitHub README / Release notes) + optional `sage-demo-preview.gif`
- Recommended walkthrough (~60–90 seconds):
  1. App launch & Control Agent (verifying Android Keystore Gemini API key + Google Drive status)
  2. *(Hardware optional)* Connecting to `SAGE-XIAO` Wi-Fi AP, live viewfinder, and 15s clip capture
  3. Background Gemini 7-pillar processing & confirmed upload to Google Drive
  4. Voice/text query in Recall Chat opening the original recorded video with transcript

*Policy: Only real, unedited or clearly labeled device recordings are permitted here.*
