# Contributing to SAGE Documentation & Releases

Thank you for your interest in **SAGE (Smriti Adaptive Guardian Engine)**.

## How the Repositories Work
- **`ByteBastion/SAGE-Product` (Public):** Product documentation, installation guides, hardware setup instructions, architecture diagrams, issue tracking, and APK releases.
- **`ByteBastion/SAGE-AI` (Public):** Academic research documentation, methodology, literature review, and pilot evaluation findings.
- **`ByteBastion/SAGE-Core` (Private):** Proprietary application source code and firmware implementation.

## Ways to Contribute Here
- **Bug Reports & Android Compatibility Feedback:** Open an issue in `SAGE-Product` with your Android OS version, device model, reproduction steps, and (if applicable) wearable firmware status.
- **Documentation Improvements:** Pull requests fixing typos, clarifying Android/ESP32 setup steps, or improving accessibility notes are warmly welcome.
- **Security Reports:** Please follow [SECURITY.md](SECURITY.md) for responsible disclosure.

## Ground Rules
- Never post API keys, OAuth tokens, or personal data in issues or pull requests.
- Do not submit pull requests containing copyrighted or third-party proprietary code.
